# AI 订单评测实验室

一个使用模拟订单数据构建的 AI 结构化提取评测 Demo，用来展示如何把“模型看起来能识别”转化为可比较、可解释、可决策的产品质量结论。

## 在线体验

- Demo：<https://yanyan-ai-order-eval.yanyanyu913.chatgpt.site>
- 个人简历：<https://yanyan-ai-testing.yanyanyu913.chatgpt.site>

## 解决的问题

企业订单进入 ERP/MES 前，需要确保客户、产品、物料、数量、规格、用纸和交期等字段完整可靠。本项目通过固定数据集和 Ground Truth 比较两个模型版本，输出：

- 字段准确率、完整率、高风险字段准确率和整单通过率；
- 缺失、错误、幻觉三类错误分布；
- 样本级证据和人工复核队列；
- 基于质量门槛的“发布 / 灰度 / 阻断”建议；
- 可下载的 JSON 评测报告。

## 产品亮点

1. **风险优先**：数量、物料、产品、用纸和交期作为高风险字段单独统计。
2. **证据定位**：每个错误都能回到样本和字段，而不是只提供一个总体分数。
3. **版本决策**：同一数据集对比 Prompt / 模型 V1 与 V2，展示改善与退化。
4. **人工兜底**：高风险错误自动进入人工复核，避免静默进入生产流程。
5. **完全可复现**：不依赖外部模型或密钥，浏览器打开即可运行。

## 数据说明

仓库内所有客户、订单、字段和值均为模拟数据，不包含真实客户资料、公司代码、内部接口或商业机密。指标仅代表该模拟数据集，不代表真实生产效果。
