# 评测设计

## 指标口径

| 指标 | 计算方式 | 说明 |
|---|---|---|
| 字段准确率 | 正确字段数 / 全部字段数 | Ground Truth 为空且预测为空视为正确 |
| 字段完整率 | 应有值且模型有输出的字段数 / Ground Truth 有值字段数 | 用于发现漏提取 |
| 高风险字段准确率 | 高风险正确字段数 / 高风险字段数 | 单独衡量生产与交付风险 |
| 整单通过率 | 所有字段均正确的订单数 / 订单总数 | 比总体字段准确率更严格 |
| 重复一致率 | 每份订单五次运行结果的一致比例均值 | 判断非确定性波动 |

## 错误类型

- `missing`：标准答案有值，模型返回空值。
- `incorrect`：模型有值，但与标准答案不一致。
- `hallucination`：标准答案为空，模型生成了无依据内容。

## 风险等级

- 高风险：产品、物料、数量、用纸、交期。
- 中风险：客户、规格、特殊工艺。

## 发布门槛

- 发布：高风险字段准确率 ≥ 95%，幻觉数为 0，整单通过率 ≥ 70%。
- 灰度：高风险字段准确率 ≥ 90%，幻觉数为 0。
- 阻断：不满足灰度条件。

门槛仅用于演示产品决策机制，真实阈值应由业务、产品、研发和测试共同确认。
